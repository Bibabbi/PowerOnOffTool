## PowerOnOffTool

一个基于 PyQt6 的图形界面应用程序，用于向串行设备发送 ON/OFF 命令序列，支持自定义延时。适用于控制电源循环、继电器开关或任何需要重复 ON/OFF 命令的串口连接设备。

## 功能特性

- 🖥️ **用户友好的图形界面** - 基于 PyQt6 构建，直观易用
- 🔌 **串口管理** - 自动检测和配置可用的 COM 端口
- ⚙️ **灵活的波特率设置** - 支持常见波特率（9600、19200、38400、57600、115200）
- ⏱️ **可自定义延时** - 在 ON 和 OFF 命令之间设置延时，支持多种时间单位（毫秒、秒、分钟）
- 🔄 **循环计数** - 实时监控已完成的 ON/OFF 循环次数
- 🛑 **开始/停止控制** - 随时轻松启动和停止命令序列
- 📊 **状态更新** - 实时反馈当前操作状态
- 🧵 **线程操作** - 使用工作线程实现非阻塞式串口通信

## 系统要求

- Python 3.7+
- PyQt6 (6.11.0)
- pyserial (3.5)

1. 克隆仓库：

git clone https://github.com/Bibabbi/PowerOnOffTool.git
cd PowerOnOffTool

\`\`\`bash
pip install -r requirements.txt

## 使用方法

1. 运行应用程序：
\`\`\`bash
python main.py
\`\`\`

2. **配置串口设置：**
   - 从端口下拉菜单中选择您的 USB 转串口设备
   - 点击"刷新"按钮检测可用端口
   - 选择合适的波特率

3. **设置命令：**
   - 输入 ON 命令（例如："ON"）
   - 输入 OFF 命令（例如："OFF"）

4. **配置延时：**
   - 设置发送 ON 命令后的延时时间
   - 设置发送 OFF 命令后的延时时间
   - 选择时间单位：毫秒、秒或分钟

5. **运行：**
   - 点击"启动"按钮开始发送命令循环
   - 点击"停止"按钮随时暂停操作
   - 监控循环计数器和状态消息

## 工作原理

应用程序执行以下流程：

1. 以配置的波特率打开指定端口的串口连接
2. 发送 ON 命令并等待指定的 ON 延时
3. 发送 OFF 命令并等待指定的 OFF 延时
4. 重复步骤 2-3，直至手动停止或发生错误
5. 跟踪已完成的循环次数并显示状态消息

## 架构设计

- **SendWorker** - 继承自 QThread 的类，在单独的线程中处理串口通信，保持 GUI 响应性
- **MainWindow** - 主窗口类，管理用户输入并显示状态

### 主要组件：

- **串口管理**：自动检测和配置
- **命令发送**：通过串口发送 UTF-8 编码的命令
- **延时处理**：精确的毫秒级时间控制
- **错误处理**：全面的异常处理和用户友好的错误消息
- **线程安全**：使用信号和槽实现安全的跨线程通信

## 信号和状态消息

- "已连接 {port}" - 成功连接到串口
- "已发送：{command}" - 命令发送成功
- "已停止" - 用户停止操作
- "循环已结束" - 循环正常完成
- "串口错误：{error}" - 串口连接错误
- "发送失败：{error}" - 命令传输失败

## 配置参数

所有设置都可通过 GUI 配置：

| 设置项 | 默认值 | 范围 |
|--------|--------|------|
| 波特率 | 9600 | 9600, 19200, 38400, 57600, 115200 |
| ON/OFF 延时 | 1000 毫秒 | 0 - 3,600,000 毫秒 |
| 时间单位 | 毫秒 | 毫秒、秒、分钟 |

## 错误处理

应用程序包含全面的错误处理：
- 端口连接错误
- 命令传输失败
- 窗口关闭时优雅关闭（等待工作线程最多 2 秒）
